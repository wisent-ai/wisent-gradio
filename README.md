# wisent-gradio

Gradio UI split out of wisent-open-source. Provides the `wisent.app` namespace.

## Install

```
pip install wisent-gradio
```

Pulls `wisent` core and `gradio` transitively. Launch with:

```
python -m wisent.app.launch
```
